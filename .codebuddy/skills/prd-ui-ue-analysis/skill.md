# PRD UI/UE分析 Skill (prd-ui-ue-analysis)

## 何时使用此Skill

在以下场景使用此Skill：

1. 分析PRD中的UI/UE需求时
2. 设计用户界面布局和交互流程时
3. 定义组件级UI要求时
4. 建立视觉设计规范时
5. 为前端开发提供详细的UI/UE实现指导时

此Skill应被 `prd-analyzer` agent 调用。

## 如何工作

### 状态转换表

#### 导入按钮状态
| 当前状态 | 用户操作 | 下一个状态 | 视觉反馈 |
|----------|----------|------------|----------|
| 禁用 | - | 禁用 | 灰色，不可点击 |
| 默认 | 选择文件 | 加载中 | 变为加载状态 |
| 加载中 | - | 加载中 | 显示加载动画 |
| 可用 | 点击导入 | 导入中 | 显示导入进度 |
| 导入中 | - | 导入中 | 禁用，显示进度 |
| 成功 | - | 完成 | 显示成功图标 |
| 失败 | - | 失败 | 显示失败图标 |

### 错误处理策略

#### 文件上传错误
| 错误类型 | 错误原因 | 用户提示 | 恢复方案 |
|----------|----------|----------|----------|
| 文件过大 | 超过5MB限制 | "文件大小不能超过5MB" | 提供文件压缩建议 |
| 格式不支持 | 不支持的文件类型 | "仅支持CSV和Excel格式" | 显示支持的格式示例 |
| 文件损坏 | 文件无法解析 | "文件已损坏，请重新上传" | 重新上传 |
| 网络错误 | 上传失败 | "网络错误，请检查网络连接" | 重试按钮 |

#### 数据验证错误
| 错误类型 | 错误位置 | 错误提示 | 处理建议 |
|----------|----------|----------|----------|
| 必填字段为空 | 行3:姓名 | "姓名不能为空" | 在预览中高亮显示 |
| 格式错误 | 行5:邮箱 | "邮箱格式不正确" | 在预览中高亮显示 |
| 数据重复 | 行7:邮箱 | "邮箱已存在" | 选择跳过或覆盖 |
| 数据过长 | 行10:备注 | "备注长度不能超过200字" | 截断或修改 |

### 用户反馈机制

#### 成功反馈
- **即时反馈**: 操作成功后2秒内显示成功提示
- **详细反馈**: 显示操作结果（如"成功导入500条，失败3条"）
- **视觉反馈**: 使用绿色成功图标和动画
- **持久反馈**: 结果页面保留成功信息，用户可查看

#### 错误反馈
- **即时反馈**: 错误发生后立即显示错误信息
- **详细反馈**: 显示错误原因和解决建议
- **视觉反馈**: 使用红色错误图标
- **可操作反馈**: 提供"重试"、"查看详情"等操作按钮

#### 进度反馈
- **导入进度**: 实时显示进度条（0%-100%）
- **导出进度**: 显示任务状态（准备中、处理中、完成）
- **网络请求**: 显示加载动画和提示文字
```

```markdown
## 组件级UI要求

### 组件1: FileUpload 文件上传组件

#### Props 定义
```typescript
interface FileUploadProps {
  /** 文件上传限制 */
  maxSize?: number  // 最大文件大小 (MB)，默认 5
  accept?: string[]  // 接受的文件类型，默认 ['csv', 'xlsx']
  multiple?: boolean  // 是否支持多选，默认 false

  /** 回调函数 */
  onFileSelect?: (file: File) => void
  onFileRemove?: () => void
  onUploadProgress?: (progress: number) => void
  onUploadSuccess?: (response: UploadResponse) => void
  onUploadError?: (error: UploadError) => void

  /** 状态控制 */
  disabled?: boolean
  loading?: boolean

  /** 自定义样式 */
  className?: string
  style?: React.CSSProperties
}
```

#### 视觉设计
- **尺寸**: 宽度 100%，高度 200px
- **边框**: 2px 虚线，颜色 `#d9d9d9`
- **背景色**: 默认 `#fafafa`，hover 时 `#f0f0f0`
- **圆角**: 8px
- **图标**: 居中显示上传图标，大小 48px，颜色 `#bfbfbf`
- **文字**: "点击或拖拽文件上传"，颜色 `#8c8c8c`

#### 交互行为
- **默认状态**: 显示虚线边框、上传图标、提示文字
- **拖拽进入**: 边框颜色变为蓝色 `#1890ff`，背景色变为浅蓝 `#e6f7ff`
- **拖拽离开**: 恢复默认状态
- **文件选中**: 显示文件信息（名称、大小、类型），提供删除按钮
- **上传中**: 显示进度条，禁用删除按钮
- **上传成功**: 显示成功图标，绿色 `#52c41a`
- **上传失败**: 显示错误信息，红色 `#ff4d4f`，提供重试按钮

#### 无障碍支持
- 按钮需要 `aria-label="上传文件"`
- 拖拽区域需要 `role="button"` 和 `tabindex="0"`
- 错误信息需要 `role="alert"`
- 键盘支持: Enter 和 Space 触发文件选择

  - hover: 背景色 `#fafafa`
  - 选中: 背景色 `#e6f7ff`

- **错误单元格**: 红色背景 `#fff1f0`，红色文字 `#cf1322`
- **警告单元格**: 黄色背景 `#fffbe6`，黄色文字 `#d48806`
- **成功单元格**: 绿色背景 `#f6ffed`，绿色文字 `#389e0d`

#### 交互行为
- **编辑模式**: 双击单元格进入编辑，失焦自动保存
- **行选择**: 点击复选框选择/取消选择，支持全选
- **排序**: 点击表头升序/降序排序，显示排序图标
- **筛选**: 表头显示筛选器，支持条件筛选
- **固定列**: 支持固定左侧/右侧列

#### 性能优化
- 使用虚拟滚动，最大渲染 100 行
- 数据超过 1000 条时使用分页
- 编辑时仅更新变化的单元格

### 步骤5: 性能体验要求

定义性能指标、优化策略、加载策略：

```markdown
## 性能体验要求

### 性能指标

#### 加载性能
| 指标 | 目标值 | 测量方法 |
|------|--------|----------|
| FCP (首次内容绘制) | < 1.5s | Lighthouse |
| LCP (最大内容绘制) | < 2.5s | Lighthouse |
| FID (首次输入延迟) | < 100ms | Lighthouse |
| CLS (累积布局偏移) | < 0.1 | Lighthouse |
| TTI (可交互时间) | < 3.5s | Lighthouse |

#### 运行性能
| 操作 | 目标响应时间 | 优化策略 |
|------|-------------|----------|
| 文件选择 | < 100ms | 优化事件监听 |
| 文件解析 | < 1s | 使用 Web Worker |
| 数据预览 | < 500ms | 虚拟滚动 |
| 导入开始 | < 200ms | 批量提交 |
| 导入进度更新 | < 50ms | 节流更新 |
| 导出生成 | < 2s | 流式生成 |

### 优化策略

#### 前端优化
1. **代码分割**:
   - 按路由分割代码
   - 动态导入大型库

2. **资源优化**:
   - 图片压缩和懒加载
   - 使用 WebP 格式
   - 启用 CDN 加速

3. **渲染优化**:
   - 使用虚拟滚动处理大量数据
   - 防抖和节流用户输入
   - 使用 React.memo 避免不必要的渲染

4. **网络优化**:
   - 启用 HTTP/2
   - 使用 Gzip/Brotli 压缩
   - 优化 API 请求次数

#### 后端优化
1. **数据库优化**:
   - 添加索引
   - 优化 SQL 查询
   - 使用批量插入

2. **缓存策略**:
   - Redis 缓存常用数据
   - 浏览器缓存静态资源
   - 接口响应缓存

3. **异步处理**:
   - 使用消息队列处理导入导出
   - 异步发送通知邮件
   - 非核心操作异步化
